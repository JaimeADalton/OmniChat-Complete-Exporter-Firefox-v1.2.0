OMNICHAT COMPLETE EXPORTER 1.2.0 — INSTALACIÓN EN FIREFOX

PRUEBA INMEDIATA (sin firma):
1. Descomprime el archivo ZIP.
2. Escribe about:debugging en la barra de direcciones.
3. Pulsa "Este Firefox".
4. Pulsa "Cargar complemento temporal...".
5. Selecciona manifest.json de la carpeta descomprimida.
6. Vuelve a la conversación de ChatGPT/Claude y RECARGA la pestaña.
7. Pulsa el icono de la extensión.
8. Para máxima cobertura, deja activadas todas las casillas y "ZIP completo".
9. Pulsa "Exportar conversación".

MEJORAS 1.2.0:
- Ejecuciones reales agrupadas como herramienta + comando + salida.
- Los ejemplos bash/python de una respuesta ya no se cuentan como comandos ejecutados.
- Detección de tarjetas de archivos y artefactos sin href.
- Resolución local selectiva de adjuntos visibles de ChatGPT cuando el backend los permite.
- Varias capturas visuales para turnos largos, con presupuesto repartido.
- Menos ruido de acciones de interfaz en las actividades.
- source-layer.json dentro del ZIP.

IMPORTANTE:
- El complemento temporal desaparece cuando reinicias Firefox.
- Firefox Release/Beta exige firma de Mozilla para una instalación permanente normal.
- El paquete .xpi incluido está SIN FIRMAR y se entrega como paquete de desarrollo/fuente.

PRIVACIDAD:
- No hay telemetría ni backend propio.
- No se sube la conversación a terceros.
- La extensión no usa el portapapeles.
- El token de sesión de ChatGPT, si se consulta para resolver un archivo visible, solo vive en memoria y no se exporta.
